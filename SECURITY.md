# Sécurité

La série 0.1.x est expérimentale. Les fichiers de dessin et patches reçus sont
des données non fiables : l’application valide tailles, références et valeurs.
Le serveur MCP utilise stdio et limite les chemins au dossier configuré.
Il n’ouvre pas de port réseau. Un patch n’exécute pas de commande système.

Pour signaler une vulnérabilité, utiliser le signalement privé GitHub :
https://github.com/Kevin-FR/DiagCraft/security/advisories/new

Si cette option n’est pas disponible, ouvrir une issue demandant un contact
privé, sans publier de fichier sensible, exploit ou secret. Ne pas inclure
les documents d’un utilisateur dans un rapport public sans son accord.
Les corrections sont annoncées dans le changelog et les releases.
