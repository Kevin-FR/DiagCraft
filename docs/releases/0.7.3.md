# DiagCraft 0.7.3

Cette version corrective expérimentale corrige le cadre sombre qui entourait
la fenêtre sous Ubuntu/Wayland.

- **Décorations Adwaita** à la place du cadre de secours sombre sans titre.
- Bordure fine, ombre transparente et titre du document visible.
- Boutons natifs, déplacement, agrandissement et redimensionnement conservés.
- Correction limitée à Linux ; comportement Mac et Windows conservé.
- Test de fenêtre complète sous Wayland sans décorations serveur, en plus du démarrage X11 du paquet Debian installé.
- Notices MIT et OFL de Cantarell incluses dans les paquets Linux, avec vérification des empreintes.

Le format `.draw` reste **v7**, l’API agents **v1**. Aucun dessin à convertir.
Seule la dépendance Linux `sctk-adwaita` 0.10.1 est ajoutée ; les autres versions
de bibliothèques restent verrouillées.

Mac : macOS 13+, **Apple Silicon sans Rosetta**, signature ad hoc sans notarisation Apple.
Windows : ZIP x86_64 portable. Linux : **`.deb` amd64** et `.tar.gz` x86_64.
Téléchargements vérifiables avec `SHA256SUMS.txt`. Les versions précédentes restent inchangées.
