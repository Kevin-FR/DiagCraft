# DiagCraft 0.4.0

Cette version expérimentale ajoute la récupération après une fermeture inattendue.

- **Copies automatiques locales** toutes les dix secondes, après les gestes terminés.
- Sauvegarde de récupération des onglets modifiés, même jamais enregistrés, avec toutes leurs pages.
- Reprise dans de nouveaux onglets non enregistrés, sans écraser les fichiers d’origine.
- Dialogue traduit dans les sept langues, accessible au lancement, dans Fichier et dans la palette.
- Action **Plus tard**, conservation des copies illisibles et confirmation avant suppression.
- Verrous natifs entre instances et transfert confirmé avant suppression d’une copie ancienne.
- Tests d’arrêt brutal réel, de concurrence, d’intégrité et des confirmations d’enregistrement.

Le format `.draw` reste **v7**, l’API agents **v1**. Aucune dépendance externe ajoutée.
Rust minimum **1.89** pour la compilation ; la chaîne fixée reste **1.94.1**.
La récupération ne remplace pas Enregistrer : les dernières dix secondes et un geste
inachevé peuvent être perdus. Les copies restent locales, sans transfert réseau.

Mac : macOS 13+, **Apple Silicon sans Rosetta**, signature ad hoc sans notarisation Apple.
Windows : ZIP x86_64 portable. Linux : **`.deb` amd64** et `.tar.gz` x86_64.
Vérifier les téléchargements avec `SHA256SUMS.txt`. Les versions publiées restent inchangées.

Guide : [récupération des dessins](https://github.com/Kevin-FR/DiagCraft/blob/v0.4.0/docs/recuperation.md).
