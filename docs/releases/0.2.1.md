# DiagCraft 0.2.1

Cette version expérimentale harmonise l’interface et ajoute une installation Debian/Ubuntu.

- Ruban compact propre à chaque onglet, sans déploiement forcé lors d’un changement.
- Commandes et icônes homogènes, en-têtes de volets identiques, rail gauche compact.
- Volets redimensionnables, limites adaptées à la fenêtre, restauration des largeurs choisies.
- Préférences d’interface locales et commande de réinitialisation sans modifier le dessin.
- Recherche de symboles dans les bibliothèques masquées ; gestionnaire toujours accessible en bas du volet.
- Paquet **.deb amd64** : application, CLI, icône, menu et association `.draw`.
  Installation, notices, MIME, exports/MCP et désinstallation vérifiés dans la CI Linux.

La numérotation conserve les versions publiées : correctifs et ajustements en
0.2.x, nouvelles capacités importantes en 0.3.0. Voir le
[guide des versions](https://github.com/Kevin-FR/DiagCraft/blob/v0.2.1/docs/versioning.md).

Le format `.draw` reste **v7**, l’API agents **v1**. Aucune nouvelle bibliothèque externe.
Les principes d’ergonomie ont été étudiés dans PDFCraft et la documentation de
draw.io ; aucun code ou asset de ces applications n’a été importé.

Télécharger le paquet de votre plateforme et vérifier `SHA256SUMS.txt`.
Mac : Apple Silicon uniquement, macOS 13+, signature ad hoc sans notarisation Apple.
Windows : ZIP portable sans signature éditeur. Linux : `.deb` amd64 et `.tar.gz` x86_64,
construits sur Ubuntu 22.04.
