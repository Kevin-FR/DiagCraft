# DiagCraft 0.1.0

Première version publique expérimentale de l’éditeur de diagrammes natif.

- Formes, textes, graphiques, bibliothèques de symboles et modèles.
- Connecteurs liés ou libres, ports et coudes, documents multipages.
- Styles, sélection multiple, alignement, navigation au trackpad et interface compacte.
- Fichiers `.draw`, galerie locale avec versions, SVG et PDF.
- Application et CLI console, inspection et patches JSON/MCP locaux.
- Sources MIT, provenance des ressources et licences incluses dans chaque paquet.

Télécharger le paquet de votre plateforme et vérifier son empreinte avec
`SHA256SUMS.txt`. Mac : Apple Silicon uniquement, macOS 13 minimum.
L’application Mac est signée ad hoc et n’est pas notariée par Apple. Les paquets
Windows sont sans signature éditeur. Linux utilise les bibliothèques graphiques
du système ; voir docs/installation.md.

Le format `.draw` v7 et l’API agents v1 sont indépendants de la version 0.1.0.
Voir ROADMAP.md pour les limitations et prochaines améliorations.
