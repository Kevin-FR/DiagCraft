# DiagCraft 0.10.0

Cette version expérimentale ajoute les images embarquées et l’export PNG.

- Import PNG/JPEG par fichiers, dépôt et commande de collage d’image.
- Normalisation PNG et réduction des grands imports, sans modifier les sources.
- Recadrage non destructif, proportions, descriptions recherchables et remplacement.
- Images intégrées aux blocs, groupes, calques, connecteurs, copies, pages et annulations.
- Export PNG de la page ou sélection : dimensions, résolution, fond transparent et adaptation aux limites.
- Rendu partagé avec SVG/PDF, y compris les masques de forme et les routes des liens sélectionnés.
- CLI d’import/export et opérations agents `add_image` / `update_image` ; inspection avec SHA-256 sans pixels base64.
- Limites d’entrée, de pixels et de documents, vérifiées avant décompression ; tests de fichiers malformés, alpha, crop, copies et compatibilité.
- Interface et README dans les sept langues, guide et démonstration originaux.

Le format `.draw` reste **v7**, l’API agents **v1**. Les anciennes applications
ignorent les images et les perdent au réenregistrement. Le collage d’image dispose
de sa commande dédiée **⌘/Ctrl+Maj+I** ; le backend de collage texte conserve ⌘/Ctrl+V.
Le [guide images et PNG](https://github.com/Kevin-FR/DiagCraft/blob/v0.10.0/docs/images.md)
décrit formats, réduction et limites.

Aucune nouvelle version de bibliothèque tierce : `image`, `png`, `base64`,
`resvg` et `arboard`, déjà présents, sont utilisés explicitement par ces fonctions.
Les notices par cible accompagnent les paquets.

Mac : macOS 13+, **Apple Silicon sans Rosetta**, signature ad hoc sans notarisation.
Windows : ZIP x86_64 portable. Linux : **`.deb` amd64** et `.tar.gz` x86_64.
Empreintes dans `SHA256SUMS.txt`.
