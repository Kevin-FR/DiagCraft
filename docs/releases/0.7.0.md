# DiagCraft 0.7.0

Cette version expérimentale facilite la recherche d’objets et le dessin au clavier.

- **⌘F / Ctrl+F** retrouve les objets de la page par texte, type ou ID ; accents et majuscules sont ignorés.
- Filtres pour formes/textes, connecteurs, traits/courbes et graphiques, avec positions X/Y.
- **Entrée** rejoint l’objet, **Maj+Entrée** l’ajoute à la sélection et **F2** modifie directement son texte.
- Liste compacte et virtualisée, longues étiquettes tronquées, libellés d’accessibilité incluant type et ID.
- Vue déplacée seulement si nécessaire ; zoom conservé quand l’objet tient dans la fenêtre.
- **R / T puis Entrée** place une forme ou un texte dans la vue, préfère un espace libre et ouvre la saisie directe.
- Deux blocs sélectionnés se relient avec **C** ; création, texte et lien restent annulables.
- Premiers caractères conservés à la sortie de la recherche et contrôle des résultats périmés.
- Douze nouveaux tests d’interface, seize messages dans les sept langues et documentation mise à jour.

Le format `.draw` reste **v7**, l’API agents **v1**. Aucune dépendance ajoutée.
La recherche porte sur la page active. Les essais utilisateurs et l’évaluation complète avec lecteurs d’écran restent à réaliser.

Mac : macOS 13+, **Apple Silicon sans Rosetta**, signature ad hoc sans notarisation Apple.
Windows : ZIP x86_64 portable. Linux : **`.deb` amd64** et `.tar.gz` x86_64.
Téléchargements vérifiables avec `SHA256SUMS.txt`. Les versions précédentes restent inchangées.

Guide : [recherche et clavier](https://github.com/Kevin-FR/DiagCraft/blob/v0.7.0/docs/recherche-objets.md).
