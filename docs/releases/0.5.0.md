# DiagCraft 0.5.0

Cette version expérimentale ajoute l’ajustement des formes au texte.

- **Ajuster la forme au texte** dans les propriétés, le menu contextuel et la palette.
- Sélections multiples, styles propres à chaque bloc et une seule annulation.
- Option **Adapter automatiquement au texte** : hauteur adaptée pendant la saisie,
  largeur conservée avec retour à la ligne ; sans retour automatique, les deux dimensions s’adaptent.
- Mesure des polices embarquées, prise en compte du chinois, des accents combinés et de la police monospace.
- Disposition du texte partagée par l’interface, SVG et PDF ; positions et connexions conservées.
- Redimensionnement manuel prioritaire : il désactive l’option dans le même geste annulable.
- API agents : champ optionnel `text_style.auto_fit` et métriques `text_layout` dans l’inspection.
- Interface en sept langues et README anglais avec six traductions complètes.

Le format `.draw` reste **v7**, l’API agents **v1**. L’option est désactivée par défaut
pour les documents existants. Deux bibliothèques déjà présentes dans Cargo.lock
sont utilisées directement par le moteur, sans modifier leurs versions.
Le PDF embarque ses polices ; l’apparence du SVG dépend des polices disponibles
dans son lecteur. Les dimensions calculées sont limitées à 20 000 px sans troncature silencieuse.

Mac : macOS 13+, **Apple Silicon sans Rosetta**, signature ad hoc sans notarisation Apple.
Windows : ZIP x86_64 portable. Linux : **`.deb` amd64** et `.tar.gz` x86_64.
Vérifier les téléchargements avec `SHA256SUMS.txt`. Les versions précédentes restent inchangées.

Guide : [ajustement du texte](https://github.com/Kevin-FR/DiagCraft/blob/v0.5.0/docs/ajustement-texte.md).
