# DiagCraft 0.7.2

Cette version corrective expérimentale améliore le placement précis au clavier.

- **Flèches : 1 px ; Maj + flèches : 10 px**, indépendamment du zoom et de la grille.
- **Maintenir une touche = une seule annulation**, avec indicateur ΔX / ΔY sur la feuille.
- **Échap** ou **Ctrl/⌘ Z pendant le geste** annule le déplacement en gardant la sélection.
- Translation commune : les blocs, graphiques, tracés et liens libres restent ensemble aux bords de page.
- Objets importés hors page déplacés progressivement, sans saut sur l’autre axe.
- Commandes disponibles dans la palette et l’aide clavier ; champs de texte et modales préservés.
- Validation avant clic, enregistrement, changement de document ou perte de focus ; récupération différée pendant le geste.
- Treize nouveaux tests, messages dans les sept langues et guide de placement.

Le format `.draw` reste **v7**, l’API agents **v1**. Aucune dépendance ajoutée.
Les essais utilisateurs et les mesures complètes avec lecteurs d’écran restent prévus.

Mac : macOS 13+, **Apple Silicon sans Rosetta**, signature ad hoc sans notarisation Apple.
Windows : ZIP x86_64 portable. Linux : **`.deb` amd64** et `.tar.gz` x86_64.
Téléchargements vérifiables avec `SHA256SUMS.txt`. Les versions précédentes restent inchangées.

Guide : [placement au clavier](https://github.com/Kevin-FR/DiagCraft/blob/v0.7.2/docs/placement-clavier.md).
