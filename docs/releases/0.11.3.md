# DiagCraft 0.11.3

Cette version expérimentale améliore la lisibilité de l’interface.

- Textes informatifs, statuts, graduations et placeholders plus contrastés ; couleurs distinctes pour les actions, avertissements et erreurs.
- Aides de navigation opaques et adaptées à la largeur disponible, même lorsqu’une page sombre passe dessous.
- Accueil des pages vides lisible sur les fonds personnalisés, sans changer les couleurs du dessin.
- Aides des connecteurs valides, invalides ou libres visibles dans tout le canevas : correction de leur disparition hors de la feuille.
- Repère de document modifié plus visible sur les onglets actifs et inactifs.
- Sept tests de peinture réelle dans les sept langues à 1200 × 680 points : glyphes, fonds, opacité, états stabilisés et conservation du document.

Voir les [critères de lisibilité et les limites des vérifications](https://github.com/Kevin-FR/DiagCraft/blob/v0.11.3/docs/readability.md).
Les parcours humains sur petit écran, les transitions animées et les lecteurs
d’écran réels restent à vérifier ; aucune conformité globale n’est revendiquée.

Le format `.draw` reste **v7**, l’API de patches **v1**. Aucune dépendance ajoutée.
Mac : macOS 13+, **Apple Silicon sans Rosetta**, signature ad hoc sans notarisation.
Windows : ZIP x86_64 portable. Linux : **`.deb` amd64** et `.tar.gz` x86_64.
Empreintes dans `SHA256SUMS.txt`.
