# DiagCraft 0.9.0

Cette version expérimentale améliore les connecteurs et leurs points manuels.

- Les connecteurs à angle droit contournent les blocs et graphiques visibles,
  avec une géométrie partagée par le canevas, les aperçus, le SVG/PDF et les agents.
- Les points manuels restent fixes et ordonnés ; seuls les chemins entre ces
  points sont calculés. Les ports choisis et extrémités libres sont conservés.
- Ajouter un point ne fige plus tous les coudes automatiques. Les déplacements
  hors grille ne sautent plus au début du geste ; une action reste annulable.
- Voies stables, préférence pour peu de coudes, calcul borné et cache de géométrie
  pour éviter les recalculs lors du zoom et des sélections.
- Signalement des contraintes impossibles et recherches limitées dans les
  propriétés et en CLI/MCP, sans altérer les points du document.
- Tests sur diagrammes denses, petits déplacements, ports, calques masqués,
  conteneurs, coordonnées précises, annulation et exports ; sept langues.

Le format `.draw` reste **v7**, l’API agents **v1**. Aucune dépendance ajoutée.
Les anciennes versions ouvrent les fichiers mais utilisent leur ancien routage.
Les lignes directes restent directes ; croisements entre liens et collisions de
libellés ne sont pas évités. Les limites du calcul et les cas bloqués sont décrits
dans le [guide des connecteurs](https://github.com/Kevin-FR/DiagCraft/blob/v0.9.0/docs/connecteurs.md).

Mac : macOS 13+, **Apple Silicon sans Rosetta**, signature ad hoc sans notarisation.
Windows : ZIP x86_64 portable. Linux : **`.deb` amd64** et `.tar.gz` x86_64.
Empreintes des téléchargements dans `SHA256SUMS.txt`.
