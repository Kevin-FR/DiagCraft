# DiagCraft 0.11.0

Cette version expérimentale ajoute les échanges Mermaid et des diagnostics
plus précis pour les agents.

- Import local d’un sous-ensemble explicite des flowcharts Mermaid, par fichier ou texte.
- Blocs et liens modifiables, textes Unicode, libellés et placement déterministe.
- Aperçu avant ajout dans une nouvelle page, vérification de révision et annulation en une étape.
- Export de la page visible avec rapport des éléments omis ou convertis, puis acceptation explicite des pertes.
- Commandes CLI avec dry-run, rapport JSON et création de fichiers nouveaux sans remplacer la source.
- Erreurs CLI/MCP avec code, opération, page, cible et piste de correction ; anciens champs texte conservés.
- Avertissements de routage et de page distingués dans l’interface des agents.
- Commandes traduites dans les sept langues, documentation et exemples originaux.

Le format `.draw` reste **v7**, l’API de patches **v1**, les quatre outils MCP
conservent leurs noms. Les styles, images, groupes, géométries et types de diagrammes
hors du sous-ensemble ne sont pas préservés par Mermaid : le rapport les signale.
Conserver le `.draw` complet comme source. Voir le
[guide Mermaid](https://github.com/Kevin-FR/DiagCraft/blob/v0.11.0/docs/mermaid.md)
et le [guide des diagnostics](https://github.com/Kevin-FR/DiagCraft/blob/v0.11.0/docs/diagnostics.md).

Aucune nouvelle dépendance ni code Mermaid incorporé.
Mac : macOS 13+, **Apple Silicon sans Rosetta**, signature ad hoc sans notarisation.
Windows : ZIP x86_64 portable. Linux : **`.deb` amd64** et `.tar.gz` x86_64.
Empreintes dans `SHA256SUMS.txt`.
