# DiagCraft 0.8.0

Cette version expérimentale ajoute l’organisation persistante des diagrammes
et inaugure les jalons de la feuille de route suivis sur GitHub.

- **Groupes** : sélection d’un ensemble, déplacement et duplication en conservant
  les écarts, regroupement et dissociation annulables.
- **Verrouillage** : objets et calques protégés contre les modifications
  accidentelles ; inspection, copie et déverrouillage restent accessibles.
- **Calques par page** : création, nom, ordre, visibilité, verrouillage et choix
  du calque de dessin dans un gestionnaire compact.
- Les calques du haut passent devant les autres, indépendamment du type des
  objets. Les formes masquées et leurs connecteurs dépendants sont exclus de
  la feuille et des exports SVG/PDF.
- Organisation conservée dans les pages, le presse-papiers, les copies,
  l’historique et la récupération locale. Dupliquer ne multiplie pas les calques.
- Huit opérations supplémentaires pour les agents CLI/MCP, avec alias de calques,
  validation des protections et application atomique.
- Commandes accessibles au clavier, dans le ruban, le menu contextuel et la
  palette ; messages et README dans les sept langues, guide détaillé en français.
- Contrôles CLI/MCP d’organisation dans les trois systèmes, en plus des tests
  du moteur et des interactions natives.

Le format `.draw` reste **v7**, l’API agents **v1**. Aucune dépendance ajoutée.
Les fichiers existants restent compatibles. Les versions antérieures à 0.8.0
ignorent les métadonnées d’organisation : elles affichent les objets masqués
et perdent groupes, calques et verrouillages au réenregistrement.
Les groupes sont plats ; redimensionnement collectif et rotation restent prévus.

Mac : macOS 13+, **Apple Silicon sans Rosetta**, signature ad hoc sans notarisation Apple.
Windows : ZIP x86_64 portable. Linux : **`.deb` amd64** et `.tar.gz` x86_64.
Téléchargements vérifiables avec `SHA256SUMS.txt`. Les versions précédentes restent inchangées.
